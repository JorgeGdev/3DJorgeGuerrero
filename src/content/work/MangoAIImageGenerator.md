<h3>AI-Powered Product Photography Revolution</h3>
MangoAI Image Generator is an intelligent image composition platform that transforms product photography into professional marketing materials using Google Gemini 2.5 Flash AI. The system seamlessly combines product photos with scene backgrounds, applies custom color palettes, and generates Instagram-ready marketing images perfect for e-commerce, social media marketers, and content creators.

<h3>Advanced AI Features</h3>
Leveraging Google Gemini AI for intelligent image composition, the platform offers custom color palette selection (up to 32 colors) to match brand identities perfectly. The dual image upload system allows users to combine product and scene photos seamlessly, while multiple style presets provide various artistic rendering modes. Each generation creates 2 unique variations for A/B testing, ensuring marketers have options to choose from.

<h3>Cloud-Powered Infrastructure</h3>
Built with Next.js 14 and TypeScript, the application integrates Supabase for asset management, database operations, and secure user authentication. The real-time processing system features a job queue with status tracking, ensuring smooth handling of concurrent requests. Interactive Polaroid-style frames provide visual feedback during the generation process, creating an engaging user experience.

<h3>Modern Tech Stack</h3>
The frontend combines React 18, NextUI components, and Tailwind CSS for a polished interface, enhanced with Framer Motion animations and React Three Fiber for optional 3D rendering. The backend leverages Google Gemini AI for image generation, Sharp for image processing fallback, and Next.js API Routes for serverless functions. All assets are managed through Supabase Storage with automatic tracking in a PostgreSQL database.

<h3>Enterprise-Ready Features</h3>
The platform outputs optimized 1080x1920 portrait images perfect for Instagram Stories and Reels. User authentication powered by Supabase Auth ensures secure access, while the job queue system handles processing with real-time status updates. The intelligent color palette system allows selection of up to 3 colors that are seamlessly integrated into AI-generated compositions.

<h3>Professional Workflow</h3>
Users simply upload their product photo (transparent PNG recommended) and a background scene image, select custom colors from the palette picker, choose a rendering style (Minimal, Vibrant, Elegant), and click generate. Within 10-30 seconds, the AI produces 2 unique variations. Users can then select their preferred variant and download the Instagram-ready image, streamlining the entire product photography workflow.

<h3>Open Source and Scalable</h3>
Licensed under MIT, the project is built for scalability and easy deployment to platforms like Railway or Vercel. The codebase demonstrates modern web development practices with TypeScript type safety, modular architecture, and comprehensive API integration. Custom styles can be added to the database, and the system supports various Gemini model options for different quality/speed tradeoffs.
